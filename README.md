# Water for All

A responsive, static website for the Water for All project.

## Pages

- Home: `index.html`
- About: `about.html`
- Projects: `projects.html`
- Get involved: `get-involved.html`
- Contact: `contact.html`

## Features

- Responsive navigation with keyboard, outside-click and breakpoint handling.
- Search and category filters for project focus areas.
- Contact enquiry form that prepares a prefilled email in the visitor's email app.
- Direct email, phone and WhatsApp contact options.

## Contact form behavior

This is a static website, so the contact form does not submit to a server and does not store messages. It opens a prefilled email in the visitor's email app for review and sending. Visitors can also use the direct email, phone and WhatsApp links on the contact page.

Before launch, confirm that the listed contact details, team members and office address are current and authorized for publication.

## Publish with GitHub Pages

The site files are in the repository root. In the repository settings, open **Pages**, choose **Deploy from a branch**, then select **main** and **/(root)** as the source.
